# Release notes — November 2026

Last updated: 2026-11-12 · Applies to: Meridian v4.6.x

Dates are production release dates; staged rollouts complete within 48 hours unless noted.

## 2026-11-01 — Billing and retention policy v4.0 in effect

Policy v4.0, announced in the [October 2026 release notes](2026-10.md), is now in effect for all
requests dated 2026-11-01 or later. The superseded pages [Billing and refunds](../policies/billing-refunds.md)
(v3.2) and [Data retention](../policies/data-retention.md) (v3.0) remain online as historical
references only. For current refund windows, administration fees, raw-data retention, audit-log
retention, export-file lifetime, and workspace purge timelines, use the v4.0 tables in the October
release note. Do not quote the older pages for current policy questions.

## 2026-11-05 — v4.6.1

**Clearer sync errors.** Connectors show a plain-language next step for `MER-2007` schema drift and
link to the matching section of [Sync schedule and troubleshooting](../data-sources/sync-schedule.md).
The error code itself is unchanged. **Fixed:** the connector diagnostics bundle could omit the
final failed run of the day when the run started before midnight UTC and ended after it; report
exports of dashboards with relative date filters now use the workspace timezone consistently with
the on-screen tile.

## 2026-11-12 — v4.6.2 and Meridian Field 3.4

**Mobile app 3.4.** Offline uploads retry photo attachments independently, so one oversized photo
no longer blocks an inspection; the app warns when the pending queue reaches **180 of 200**
records. Minimum supported server version is v4.4; see
[Mobile app](../product/mobile-app.md). **API `GET /usage`:** Owners, Admins, and Analysts can read
current rate-window usage and daily export counts, while `GET /health` stays unauthenticated and is
not rate limited; see [Query API](../api/query-api.md). **Audit-log export:** audit logs can be
exported as CSV by Owner or Admin, and exporting is itself an audit event. **Fixed:** a workspace
downgraded at renewal could exceed the new plan's connector limit without showing the read-only
banner; the banner now appears at renewal.
